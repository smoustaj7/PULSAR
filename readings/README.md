# Astronaut Health Monitor: Data README

This folder holds the data behind the dashboard. It mixes **real** data from NASA's Open Science Data Repository (OSDR) with **simulated** data. Every row carries a `kind` column (`real` or `simulated`) so the two are never confused.

## 1. Where the data comes from

| Part | Origin | Kind |
|---|---|---|
| Blood counts, metabolic panel, cardiovascular proteins | Inspiration4 (I4) crew, OSDR studies **OSD-569** and **OSD-575** | Real |
| Sex of each crew member | OSD-569 metadata (`s_OSD-569.txt`, column `Characteristics[Sex]`) | Real |
| Vitals (heart rate, BP, SpO₂, temperature, CO₂, sleep) | Generated by `simulate.py` | Simulated |
| Sex hormones, bone markers, radiation dose | Generated by `simulate.py` | Simulated |

**Why simulate?** None of the OSDR studies used here contain wearable or vital-sign data. The vitals are therefore simulated, and the real I4 data serves as supporting evidence (blood biology).

**Crew** (4 people, 2 men and 2 women):

| subject | sex |
|---|---|
| C001 | M |
| C002 | F |
| C003 | F |
| C004 | M |

**Important:** with 2 people per sex, no statistics can be computed per sex. Show each crew member individually.

## 2. How the files are produced

```
raw/ (OSDR downloads)  ->  python simulate.py  ->  5 CSV files  ->  app.py (dashboard)
```

`simulate.py` reads the OSDR files in `raw/`, adds sex and flags, generates the simulated indicators with a fixed random seed (42, so results are reproducible), and writes the five CSV files below.

## 3. Files

### 3.1 `crew_sex.csv` (real)
One row per crew member.

| Column | Meaning |
|---|---|
| `subject` | Crew ID (C001 to C004) |
| `sex` | `M` or `F` |

### 3.2 `vitals_simulated.csv` (simulated)
Long format: one row per subject, day and indicator. 7,000 rows. Mission days 0 to 179.

| Column | Meaning |
|---|---|
| `subject`, `sex` | Crew ID and sex |
| `day` | Mission day (0 to 179) |
| `indicator` | Which indicator (see section 4) |
| `value` | The measurement |
| `device` | Measurement device the indicator is attributed to |
| `cycle_phase` | `follicular` or `luteal` for women; `n/a` for men (see note below) |
| `b_mean`, `b_sd` | The person's own baseline (mean and standard deviation over days 0 to 13), core indicators only |
| `z_personal` | (value − b_mean) / b_sd: how far the value is from the person's own baseline; core indicators only |
| `alert` | `True` if the value crosses an alert threshold |
| `kind`, `source` | Always `simulated`, `simulation` |

> **Loading note:** `"n/a"` in `cycle_phase` is read as empty by pandas. Load with `pd.read_csv("vitals_simulated.csv", keep_default_na=False, na_values=[""])`.

## 4. Simulated indicators

### 4.1 Your 7 core indicators

| `indicator` | Name | Unit | Device | Baseline (M / F) | Alert |
|---|---|---|---|---|---|
| `rhr` | Resting heart rate | bpm | Wearable or BP cuff | 65 / 70 | none |
| `sbp` | Systolic blood pressure | mmHg | Smart BP cuff | 120 / 114 | > 140 |
| `dbp` | Diastolic blood pressure | mmHg | Smart BP cuff (same reading) | 77 / 72 | > 90 |
| `spo2` | Blood oxygen saturation | % | Bluetooth pulse oximeter | 97.5 / 97.5 | < 95 |
| `temp` | Body temperature | °C | Bluetooth thermometer | 36.6 / 36.6 | > 37.8 |
| `co2_ppm` | Cabin CO₂ | ppm | Station environmental sensors (telemetry feed) | 3500 / 3500 | > 5000 |
| `sleep_h` | Sleep duration | hours | Wearable sleep tracker | 6.0 / 6.0 | none |

Every day, each value is drawn from a normal distribution around the baseline, with these standard deviations: RHR 4, SBP 6, DBP 4, SpO₂ 0.6, temperature 0.15, sleep 0.6, CO₂ 300.

What changes over time or by sex:

- **RHR** drifts up by 0.01 bpm per day (a simple deconditioning effect).
- **SpO₂** drifts down by 0.002 per day and is capped at 100.
- **Women, luteal phase** (second half of a 28-day cycle): temperature +0.4 °C, RHR +3 bpm, sleep −0.3 h.
- **Sex baselines** differ for RHR, SBP and DBP.
- **CO₂** is an environmental measurement and has no sex effect.
- The alert thresholds are the same for everyone.

### 4.2 Sex-related and extra indicators

| `indicator` | Name | Unit | Sampling | Men | Women |
|---|---|---|---|---|---|
| `estradiol_pgml` | Estradiol | pg/mL | Weekly | ~25 | ~80 follicular, ~150 luteal |
| `progesterone_ngml` | Progesterone | ng/mL | Weekly | ~0.3 | ~0.6 follicular, ~10 luteal |
| `testosterone_ngdl` | Testosterone | ng/dL | Weekly | ~600 | ~35 |
| `ctx_ngml` | CTX (bone resorption marker) | ng/mL | Weekly | ~0.35 | ~0.30 |
| `p1np_ngml` | P1NP (bone formation marker) | ng/mL | Weekly | ~50 | ~45 |
| `dose_msv` | Cumulative radiation dose | mSv | Daily | same | same |
| `dose_pct_limit` | Dose as % of career limit | % | Daily | same | same |

- Weekly indicators are recorded on days 0, 7, 14, and so on (26 draws per person).
- `ctx_ngml` rises by 0.0008 ng/mL per day (bone resorption increases in microgravity).
- Radiation accumulates at about 0.5 mSv per day. `dose_pct_limit` is the dose divided by a 600 mSv limit. An alert fires above 80%.
- `z_personal` is not computed for these indicators.

## 5. Timepoints in the real data

The I4 labs were drawn at 7 timepoints. `L-` means days before launch and `R+` means days after return. I4 itself was a short flight of about 3 days.

| `tp` | `day` | `phase` |
|---|---|---|
| L-92 | −92 | pre-flight |
| L-44 | −44 | pre-flight |
| L-3 | −3 | pre-flight |
| R+1 | 1 | post-flight |
| R+45 | 45 | post-flight |
| R+82 | 82 | post-flight |
| R+194 | 194 | post-flight |

Plot these on a categorical axis in this order. **Do not overlay them on the 180-day simulated vitals**, because the real data is a short flight followed by recovery, while the simulation covers a long mission.

## 6. Real lab indicators (`labs_real.csv`, `labs_recovery.csv`)

| `analyte` | Name | Unit | Why it matters | Study |
|---|---|---|---|---|
| `hemoglobin` | Hemoglobin | g/dL | Oxygen-carrying capacity; reference range differs by sex | OSD-569 (CBC) |
| `hematocrit` | Hematocrit | % | Share of blood volume made of red cells; differs by sex | OSD-569 |
| `red_blood_cell_count` | Red blood cell count | million/µL | Red cell number; differs by sex | OSD-569 |
| `creatinine` | Creatinine | mg/dL | Kidney function; differs by sex | OSD-575 (CMP) |
| `egfr_non_african_american` | Estimated GFR | mL/min/1.73 m² | Kidney filtration; only a lower limit (60) exists | OSD-575 |
| `glucose` | Glucose | mg/dL | Metabolism | OSD-575 |

**Reference ranges and flags.** The ranges come from the laboratory's own reporting in the source files. They are sex-specific for hemoglobin, hematocrit, RBC and creatinine. In the raw files, one woman (C003) had some rows carrying the male range. `simulate.py` sets one consistent range per sex (`NORMALIZE_RANGES = True`), using the female range from the file for women and the male range for men.

| Analyte | Female range | Male range |
|---|---|---|
| Hemoglobin (g/dL) | 11.7 to 15.5 | 13.2 to 17.1 |
| Hematocrit (%) | 35.0 to 45.0 | 38.5 to 50.0 |
| RBC (million/µL) | 3.8 to 5.1 | 4.2 to 5.8 |
| Creatinine (mg/dL) | 0.5 to 1.05 | 0.6 to 1.35 |

**Known issues to mention when presenting:**

- The source file labels the hemoglobin unit as "percent". The values (11.5 to 17.0) are in g/dL, so `simulate.py` sets the unit to `gram_per_deciliter`.
- Some glucose values go as low as 36 mg/dL, which is not physiologically plausible and may be a sample artifact. Treat glucose with caution or leave it out of the sex-related panel.
- A `low` or `high` flag is an observation about one person at one time. It is not a diagnosis.

## 7. Cardiovascular proteins (`cardio_real.csv`)

Nine serum proteins from OSD-575, each in two forms, giving 18 `indicator` values:

| Protein | `indicator` prefix | Concentration unit |
|---|---|---|
| Alpha-2-macroglobulin | `a2_macroglobulin` | ng/mL |
| Alpha-1-acid glycoprotein | `agp` | ng/mL |
| C-reactive protein (inflammation) | `crp` | pg/mL |
| Fetuin A36 | `fetuin_a36` | ng/mL |
| Fibrinogen (clotting) | `fibrinogen` | ng/mL |
| Haptoglobin | `haptoglobin` | ng/mL |
| L-selectin | `l_selectin` | pg/mL |
| Platelet factor 4 | `pf4` | ng/mL |
| Serum amyloid P | `sap` | pg/mL |

Each protein appears as `<prefix>_concentration_<unit>` and `<prefix>_percent`. Check the OSD-575 documentation for how the percent form is defined before explaining it. Use this file as the **supporting research** panel: it shows cardiovascular and inflammatory biology after flight, not blood pressure or heart rate.

## 8. Limitations (say these out loud)

1. **The vitals are simulated.** They illustrate how the dashboard would behave with real device data. They are not measurements.
2. **All baselines, hormone, bone and radiation numbers are assumptions**, typical adult ballparks chosen for the demo. Replace them with cited reference values before drawing any conclusion.
3. **The radiation career limit (600 mSv) is an assumption to verify** against the current NASA standard.
4. **Four crew members only** (2 men, 2 women): no statistical comparison between sexes is possible.
5. **The real data does not contain heart rate, blood pressure, SpO₂, temperature, cabin CO₂ or sleep.** The studies show related biology only.
6. **Real and simulated timelines differ** (a short flight plus recovery versus 180 mission days), so they are shown in separate panels.

## 9. Reproducing the data

1. Put the OSDR files in `raw/` (CBC and CMP and cardiovascular CSVs, plus the OSD-569 ISA metadata zip).
2. Run `python simulate.py`.
3. Run the dashboard with `streamlit run app.py`.
